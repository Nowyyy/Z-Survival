- Murs : épaisseur 40, face intérieure sur la limite de déplacement (`room.wall` = 24, inchangé) ; les 16 de plus débordent vers l'extérieur. Hauteur 60. Fenêtres = vraies ouvertures (allège, linteau, 2 barreaux).
