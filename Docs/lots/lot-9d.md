## Démarrage allégé
- Cause relevée : l'élément LCP de Lighthouse (écran portrait) est `#rotate`, posé par `boot.js`, qui attendait tout le graphe de `demarrage.js` ; celui-ci tirait `graphics-boot.js` et la carte (`maps`, `decor`, `epaves`, `shape`, `floors`, `collision` : ≈ 118 Ko). `js/menu/adresse.js` lit l'adresse (même résultat, testé) ; `graphics-boot.js` vient à « JOUER » et aux Options. Menu : **36 → 30 fichiers JavaScript, 56 → 50 requêtes, 1,04 → 0,92 Mo** ; partie : 113 → 121 fichiers JavaScript (+ ces 7 et `liberation.js`), aucune requête externe. `menu.css` non découpé (hors du chemin de l'élément LCP ; voir Idées) ; préchargement des modules essayé, sans effet mesurable, retiré.
- **Lighthouse mobile, 5 passes, médianes** : `jeu.html` **75 → 79** (avant 75, 76, 75, 73, 76 ; après 79, 76, 82, 79, 83 ; FCP 3,19 → 2,93 s, LCP 5,10 → 4,50 s, TBT 0, CLS 0,001 → 0) ; `index.html` **90 → 90** (CLS 0).
