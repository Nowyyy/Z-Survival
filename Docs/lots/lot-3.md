**Choix.** Valeurs de la spécification, toutes provisoires. Écarts : (1) la spécification annonce « cinq sons » mais en liste quatre (`fenetre-escalade` n'existe pas) : quatre sons, 10 variantes, 0,6 Mo. (2) `chutes` et `reparation` sont dans une section `extra` de `player-stats.json` et `parseLevelsParam` renvoie `extra` en plus de `levels` : les tests du lot 2b exigent sept clés dans `STAT_IDS`, `normalizeLevels` et `all:5` ; `getState().stats.levels` garde les sept, `extraLevels` porte les deux autres. (3) Planches : poutres en relief (face avant, dessus, deux bouts : 8 triangles) de 14 d'épaisseur, posées contre la face intérieure du mur, de travers (jusqu'à 13°), débordant de 16 autour de l'ouverture, région `bois` de l'atlas (variante « I » choisie sur comparaison) ; chaque planche arrachée apparaît en débris à plat sur le sol devant la fenêtre (retours du propriétaire sur téléphone : planches invisibles dans l'ouverture, puis en diagonale ; le maillage ne suivait pas chaque planche, corrigé). (4) Un arrivant rejoint la file à `max(140, 45·(k+1)+40)` de `entryOuter` (sinon la file de 6 serait hors d'atteinte du seuil de 140) ; l'escalade attend d'être au bord (3 s au plus). (5) Recettes : arrachage = rafale passe-bande 3 → 1,2 kHz + seconde rafale + scie 800 → 1 600 Hz + coup sourd, réverbération courte ; pose = 3 coups (bruit lowpass + sinus 420 → 260 Hz) à 0, 130 et 270 ms ; chute = sinus 90 → 45 Hz + bruit brun + souffle rose + sinus 3,3 kHz très faible ; relevage = bruit rose montant puis pas lourd. (6) `setChutes(n)` ajouté aux hooks pour les tests de mort des lots précédents.
