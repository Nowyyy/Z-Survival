# Noms et descriptions des versions et des lots affichés sur l'accueil de la Recette.
# Un bloc par version ou par lot : l'identifiant entre crochets ([v0.6] = version, [lot-5a] = lot), puis une ligne par information « clé: valeur ».
# Clés : nom (60 caractères au plus ; version : l'étiquette, par exemple V0.4 ; lot : le titre), description (une ligne, 200 caractères au plus).
# Pour un lot seulement : version (version de rattachement, par exemple v0.6) et afficher (oui ou non ; non = absent des évolutions en cours).
# Ce fichier l'emporte sur versions.json et data/changelog.json ; une ligne absente garde le texte d'origine ; les lignes en # sont des commentaires.
#
# Exemple :
#   [lot-5a]
#   version: v0.6
#   nom: Voiture en flammes et hélicoptère écrasé
#   description: Phrase courte qui décrit l'évolution.
#   afficher: oui
#
# Pour corriger une faute : modifie la ligne, valide ; la Recette est mise à jour après le déploiement de `dev`.
